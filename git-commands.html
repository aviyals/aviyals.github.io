Basic Git commands.

Use these everyday commands to create a repository, inspect and save changes, work with branches, and share your work.

Everyday reference

Commands by task

Run commands from your project directory. Replace example names and messages with your own.

Create and save

Start tracking a project, stage files, and record a commit.

git init
git status
git add .
git commit -m "Initial commit"

Inspect changes

Check what changed before staging or committing your work.

git status
git diff
git log --oneline

Work with branches

Create a branch for focused work, then switch back and merge it when ready.

git switch -c feature/login
git switch main
git merge feature/login

Share changes

Connect to a remote repository and publish your branch. Replace URL with the remote repository URL.

git remote add origin URL
git push -u origin main
git pull

Undo safely

Review changes first. Restore discards uncommitted file changes; revert creates a new commit that undoes an earlier commit.

git diff
git restore file.txt
git revert COMMIT_ID

Rename a branch

First check the current branch. Continue only if it is feature/1124-employee-login.

git branch --show-current

Example output:

feature/1124-employee-login

Rename it, then check the result. This changes the local name only; it does not rename a remote branch.

git branch -m feature/1124-employee-login fix/1124-employee-login
git branch --show-current
