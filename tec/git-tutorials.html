Basic tutorials

A short path from your first repository to a clean team workflow.

1. Create a repository

Initialize a project, check its status, and make your first commit.

git init
git add .
git commit -m "Initial commit"

2. Work with branches

Keep feature work separate, then bring it back into the main branch.

git switch -c feature/login
git switch main
git merge feature/login

3. Share changes

Connect a remote repository and publish your local branch.

git remote add origin URL
git push -u origin main
git pull

4. Undo safely

Inspect changes before deciding whether to restore, reset, or revert them.

git diff
git restore file.txt
git revert COMMIT_ID

5. Rename a branch

Rename feature/1124-employee-login to fix/1124-employee-login locally.

  1. Verify the current branch. Continue only if the output is feature/1124-employee-login. If it is different or empty, stop and switch to the intended branch first.

    git branch --show-current

    Sample output:

    feature/1124-employee-login

  2. Rename the branch using its existing and new names.

    git branch -m feature/1124-employee-login fix/1124-employee-login

  3. Verify that the current branch is now fix/1124-employee-login.

    git branch --show-current

    Sample output:

    fix/1124-employee-login

This changes the local branch name only; an existing remote branch is unchanged.
